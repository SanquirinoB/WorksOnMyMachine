# Referencia visual de origen

Los documentos de Spec son una copia histórica del diseño de DeadDraw que dio origen a CoreKitBasicUI. Describen el preset visual y su contexto original; sus referencias a gameplay, mapas, herramientas o fases de DeadDraw no son requisitos del módulo reutilizable. La API, instalación y validación vigentes están en ../CoreKitBasicUI.md y ../BasicUIValidation.md.
