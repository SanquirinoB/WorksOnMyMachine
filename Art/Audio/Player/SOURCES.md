# Player sound effects

These mono 48 kHz WAVs are the reimport sources for `/Game/Delerict/Audio/Player`. Each mixes short clips from the team's local Kenney library, with edits to pitch, length and level.

| Game sound | Source recordings |
| --- | --- |
| Boot steps 01–03 | `footstep_concrete_000`–`002`, each paired with the corresponding `impactMetal_light_000`–`002` |
| Boot latch | `impactMetal_medium_000` and `switch_001` |
| Boot jump | `switch_002` and `thrusterFire_001` |
| Item grab | `click_001` and `card-slide-4` |
| Item throw | `card-slide-4` and `impactMetal_light_000` |

Kenney released the source recordings under CC0. [Impact Sounds](https://kenney.nl/assets/impact-sounds) · [Interface Sounds](https://kenney.nl/assets/interface-sounds) · [Sci-Fi Sounds](https://kenney.nl/assets/sci-fi-sounds) · [Casino Audio](https://kenney.nl/assets/casino-audio)
